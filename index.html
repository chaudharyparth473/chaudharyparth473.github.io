01 About

Hi. Pull up a chair.

I'm Parth. I started out in a BCA program writing PHP and HTML for little websites, and somewhere along the way I got more curious about how those websites get broken than how they get built. That curiosity turned into cybersecurity, and now I'm doing a master's in it.

What I like most is the moment something clicks: a port scan that shows a door nobody meant to leave open, or a one-line fix that turns a SQL injection into a boring, harmless error. I like small tools that do one job and explain themselves, which is why my projects are a password vault and a link checker rather than a giant platform. My master's adds the other half of the story: digital forensics, working out what happened after the door was already opened.

Away from the keyboard I play football (I'm slightly smug about the 1st rank at our college sports day) and I walk up mountains. Sar Pass, Kedarkantha and Friendship Peak so far, with the last one reaching 17,350 ft. Hiking turns out to be good practice for security work: you plan, you check your gear twice, and you don't skip the boring safety steps.

I'm looking for an entry-level cybersecurity analyst or security trainee role where I can keep learning from people better than me.

02 Work, newest first

Oct 2026IBM Cybersecurity course

VaultGuard

A password vault that never leaves your laptop.

It began as a command-line vault with a strong-password generator, and the version on GitHub now wears a dark Tkinter GUI. Everything stays offline. Your master password is stretched with scrypt, and the vault itself is sealed with AES-256-GCM, so tampering gets caught instead of silently decrypted into garbage.

It's one Python file with one dependency. I also wrote 23 security tests for it, because I didn't want to just trust my own crypto and hope for the best.

  • Tkinter
  • AES-256-GCM
  • scrypt

Phishing Detector

Paste a link. Get a verdict, plus the reasons.

A rule-based tool that scores a URL as LOW, MEDIUM or HIGH phishing risk and tells you why, using 12 heuristic checks. It never visits the link, so you can't get caught by the thing you're inspecting, and there's nothing to install.

Oct 2026IBM Cybersecurity course

Shift-left code review

Catch the bug before it ships.

I took a sample web app and hunted down three classes of problems: SQL injection, passwords written to logs in plain text, and weak cryptographic dependencies. I scanned it with IBM Bob and Snyk (static and dependency analysis), wrote a custom rule file for automated review, swapped Statement for PreparedStatement, and then proved every fix with a test.

  • Java
  • IBM Bob
  • Snyk SAST + SCA
  • SQLi
